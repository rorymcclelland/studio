# 0011 Ads composed in code: ImageResponse, bundled fonts, contrast and fit decided before drawing

**Date:** 26 October 2026. **Status:** accepted (built in Sprint 5: S5-3 rendering core, `src/lib/creative/render/`).

**Context.** Rule 8 (decision 0005) says the image model never draws text, so every word, logo and legal line on an ad is drawn in code. S5-3 asks for three 1080 × 1080 layouts that are on-brand and legible by construction, with Rory's answer Q7: a small set of bundled open fonts, each brand font mapped to its nearest, with the mapping shown, and no network call while rendering.

**Decision.**
- **Renderer.** `renderAd()` draws with `ImageResponse` from `next/og` (Satori, then sharp or resvg). It runs outside a route handler on the Node runtime, so the route, workflows and tests use the same function; the PNG is read from the response body. A layout that can't be made reliable in Satori falls back to SVG drawn in code and rasterised with resvg, measured with the font file (not needed so far).
- **Fonts.** Inter and Source Serif 4 (SIL OFL) from `@fontsource`, as woff (Satori takes ttf, otf or woff, not woff2), weights 400, 600 and 700, read from `node_modules` and cached. Serif names (Georgia, Times, Garamond and others) map to Source Serif 4; sans and unknown names map to Inter, and the note says which ("drawn with Source Serif 4, the nearest open font to Georgia"; "drawn with Inter: no bundled open font is close to X"). The files reach every server function through `outputFileTracingIncludes` (`/**`, six files) in `next.config.ts`, which was checked in a build trace.
- **No network.** Satori fetches a Google font for characters its fonts lack, and emoji from a CDN. Copy that uses characters outside the bundled Latin fonts is refused with the characters named, rather than fetched.
- **Contrast in code.** The text colour and its panel or scrim come from the palette and must reach 4.5:1 (body, legal, button words; the headline shares the text colour, so it passes its 3:1 too). Otherwise near-black #111 or white on a palette colour, or on a darkened or lightened palette scrim; fallbacks aim for 7:1 where they can. If nothing reaches AA, the ad is refused. Ratios are recorded rounded down, so a recorded 4.5 really passes. Words on Full bleed sit only on the solid part of the scrim, where the ratio is measured. The button is the first palette colour that stands out from the panel by 3:1 and carries AA words, else the text pair inverted.
- **Fit in code.** Text is measured with the font file (`opentype.js`, glyph advances and kerning) and drawn line by line as measured, so the recorded line count is what is drawn. Each layout has sizes, line limits and a height budget; the fit takes the largest headline, then body, size that fits, and otherwise refuses with "headline too long for Split" (or body, call to action, legal lines).
- **Logos.** A logo's SVG `<text>` is outlined into paths with the mapped bundled font, so a wordmark looks the same on any host, and its empty margin is trimmed (sharp) so it fills its plate. Logos sit on a light palette plate wherever they cross a picture or a dark panel.
- **Legal lines.** All of the kit's legal lines are drawn at 22 px or more; lines that don't fit are refused, never dropped. A kit with none draws none, and the checks say "no legal line in the kit".

**Consequences.** Ads are deterministic and need no network. Brands get one of two families until more fonts are bundled (backlog if a demo needs a display or monospace face). Satori's own shaping can differ from the measurement by a few pixels a line, which the margins and button padding absorb. Logo colours are not contrast-checked, which is why they sit on a plate. The first render in a process takes about 0.7 s (loading fonts and the renderer); later ones about 0.2 to 0.3 s.

**Samples.** `docs/design/sprint-5-layouts/` holds the three layouts for both demo brands, plus the grey-palette fallback and the longest Split copy. Their pictures are gradients made in code (sharp), standing in for generated images; regenerate them with `RENDER_SAMPLES=1 npx vitest run tests/lib/render-ads.test.ts`.
