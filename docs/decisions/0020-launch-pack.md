# 0020 The launch pack: one streamed zip of the picked ads, with two manifests and a README

**Date:** 2 November 2026. **Status:** accepted (built in Sprint 7: C7-3, with Rory's answer Q6).

**Context.** A marketer launching a campaign needs every picked ad in every size its channel uses (C7-1, decision 0018) and in each of the brand's languages (C7-2, decision 0019), with a record of what each file says and how it was checked. Ads are drawn on request and never stored. Vercel caps a buffered function response at 4.5 MB; a streamed response is not capped. Rule 1 says simulated pictures and words, and machine translations, are labelled wherever they are shown; rule 3 that people approve anything that spends, publishes or replaces creative; rule 7 that every read goes through the workspace's access check.

**Decision.**
- **Picked ads only, no approval** (Q6). The pack holds the current picked ads of the signed-off brief version: not unpicked or discarded ads, not ads whose picture or words were discarded, not picks left on an earlier version. A download publishes nothing and spends nothing (it is code only, no model call), so it needs no approval; the approval will come when anything is launched (Sprint 8 onwards).
- **One address:** `/campaigns/<id>/pack.zip` (`src/app/(app)/campaigns/[id]/pack.zip/route.ts`, logic in `src/lib/creative/pack.ts`). No session, a malformed id and another workspace's campaign are the same plain 404 (the campaign is read through `asUser`, so row-level security decides). A brief that isn't signed off, or a campaign with nothing picked, is a 409 with the reason as plain text, never an empty zip; the gallery shows the same reason and offers no download. `maxDuration` is 300 seconds.
- **Planned, then drawn.** The pack is planned without drawing: for each picked ad, language and size, the words, the language's legal lines and the frozen kit are fitted as `drawInSize` would draw them (`fitInSizes`, decision 0019). The plan gives the gallery its count and its left-out list before the download. Fits are cached in-process by copy set, layout, kit and renderer version (copy sets never change), so the campaign page's refreshes don't refit; the first plan of a process takes about 2.5 s (the fonts load), later ones about 30 ms.
- **Streamed with fflate,** one size at a time. The response body is a `ReadableStream` whose `pull` draws the next file and pushes it into fflate's `Zip` (PNG files stored as they are, since they are already compressed; the manifests and README deflated). The reader's pace sets the drawing's pace (backpressure), and nothing is held but the current ad's picture (converted to PNG once per ad) and the file being written. Pack drawings don't go into the size-drawing cache (`drawInSize(..., { remember: false })`), so a 64-file pack doesn't push out the gallery's drawings. If a size that fitted when planned can't be drawn, it moves to Left out with the reason; the manifests and README are written last, from what was actually drawn.
- **Folders and names:** `<channel>/<language>/ad-<NN>-<size>-<headline-slug>.png`, for example `paid-social/de-DE/ad-02-1080x1920-sieh-wohin-dein-geld-geht.png`. The channel and language folders are fixed strings; the ad number is the ad's number in the gallery; only the slug comes from words, and it is ASCII letters, digits and hyphens (accents folded, ß as ss, soft hyphens dropped, 40 characters at most), so no headline can make a path (`../../x` becomes `x`). The zip is named `<brand-slug>-launch-pack-<London date>.zip`.
- **Every language:** English, then each language the brand has chosen or the ad's words have a current translation in. A chosen language with no current translation for an ad is listed as left out ("There are no Spanish words for this ad: Translate the picked ads writes them, or its Translate run says why a translation was left out"), or with the language's refusal when it has no legal lines.
- **`manifest.json`:** the pack (made when, by Studio, the campaign, brand, brief title, version and sign-off time, counts, and the honesty labels that apply), then one entry per file: file name, ad id and number, channel, audience (F-27), size, language, layout drawn, headline, body, button, legal lines, alt text (the picture's idea from the Imagery agent, in English, then the words), checks (the contrast ratios, the fit with its type sizes, legal lines present, logo, the simulated label drawn), provenance (picture model or "simulated (mock image model)", words from the Copy agent, a person, the mock model or a machine translation, with the copy set and run) and labels; then **Left out**, each with ad, size (or "every size"), language and reason.
- **`manifest.csv`:** the same, one row per file (status `included`) and per left-out item (status `left out`, with the reason), every field quoted, a UTF-8 byte-order mark so spreadsheets read accents, CRLF line ends, and a leading `=`, `+`, `-`, `@`, tab or return defused with an apostrophe so no cell runs as a formula.
- **`README.txt`:** what the pack is, the campaign, brief version and sign-off date, when it was made, the folders, how many files and what was left out, that nothing was published or spent, and the honesty labels: how many files use simulated pictures, have simulated words, or are machine translations (with `MACHINE_TRANSLATION`'s explanation, and the simulated translation's when the mock wrote them).
- **The gallery** (`launch-pack.tsx`, under the Languages bar) shows the pack before download: the number of ads and of files in the zip, per language, the sizes per channel, the labels that apply, and a disclosure listing everything left out with its reason. **Build launch pack (64 ads)** is a plain link with `download` (not `next/link`, so it is never prefetched), with the time it will take. It renders in its own Suspense boundary so the plan never holds up the gallery.

**Measured.** The story's demo (Quillmoor, four picked paid-social ads, translated by the mock model into French, German and Spanish) is 64 ads plus three files: 22.6 MB, downloaded completely in 29.0 s through the dev server (e2e, `tests/e2e/launch-pack.spec.ts`), about 0.45 s a file. A 40-file pack in the database test took 19 to 21 s and 15.0 MB; the test process's resident memory rose from about 185 MB to a plateau of 560 to 625 MB while drawing (Satori, resvg and sharp working memory, collected as it goes), not growing with the number of files. Vercel's functions have 2 GB.

**Consequences.** A pack is drawn afresh at every download (nothing is stored), so a large pack takes time: about half a second a file, so a pack of 300 files would need most of the 300 s limit; packs that large would need drawing in parallel or storing (backlog if it comes up). The browser shows the download as it arrives, but a failure part-way (a dropped connection, the time limit) leaves an incomplete zip that won't open; the person downloads again. The alt text describes the picture in English in every language's entry. The demo found a C7-2 bug: the English first-person check used ASCII word boundaries, so French "même" read as "me" and refused a mock translation; it now uses Unicode letter boundaries (`copy-rules.ts`, with a test).
