# 0011 Copy agent: checked words per audience and channel, replaced only by a person

**Date:** 26 October 2026. **Status:** accepted (built in Sprint 5: S5-2).

**Context.** S5-2 adds the Creative squad's first agent. Its words go straight into ads, so they must be honest (rule 1), name no other brand (rule 2), and never replace creative without a person (rule 3). The refinement fixed the channels, limits and checks; this record covers what it left open.

**Decision.**
- **The gate.** A Copy run starts only when the campaign is `approved`, and reads the `approved_version` brief. A draft, a brief awaiting sign-off, or one edited after sign-off is refused with "Sign off the brief before making copy", both when the run is started and again inside the workflow before any model call.
- **What is written.** Code makes the list of jobs (channel, audience tag A1..An, number of sets) from the brief, and the model writes exactly that list. Paid social and display get three alternatives per audience, and search, email and app push one set each. Out-of-home is left out with a note in the run's output. A brief with no audiences gets one audience, tagged `all`. Display's call to action follows paid social's 20-character limit, since the refinement's table gives display only a headline and a body.
- **Checks in code** (`src/lib/creative/copy-rules.ts`), shared by the agent (one repair) and hand edits: field limits; figures must be in the brief's cited items (its insights' sources and its audiences' segments), unit for unit, using `figuresIn`, `figureSupported` and `quantityInWords`; banned terms and claims that need evidence (`containsTerm`); the market notes' real names; any other capitalised name that is not the brand, its products, its customers' places, a date or a common word (`undeclaredNames`, as for market notes), so copy is written in sentence case; repeated alternatives; and no repeated legal lines.
- **Testimonials refused (Q8), defined precisely:** (1) no quotation marks: double quotes of any kind, or single quotes used as quotation marks (apostrophes are fine); (2) no first-person singular voice (I, I'm, me, my, mine, myself) outside a call to action, because the brand speaks as "we" to "you", so "I" reads as a customer's words ("Start my plan" is allowed as a button); (3) no words attributed to someone: a name after a dash at the end (but not the brand's own sign-off), a person or customer who says, said or told us something, or a star rating.
- **Legal lines** are never written by the model. Code stores the kit's legal lines with every set when it is saved (`copy_sets.legal_lines`), so a later change to the kit doesn't change ads already made.
- **Hand edits** are new rows (`source = 'person'`, `based_on` the old set), and the old set is marked discarded in the same transaction. The same checks apply, except that a typed figure is allowed. The figure is marked "added by a person" when the sets are read (computed against the brief's evidence, as S3-3 does for briefs), not stored. Loose quantities in words are still refused, because a typed figure can be marked and checked, but "most savers" can't be.
- **New words** is a Copy run limited to one set's channel and audience, with the old words in the prompt. It writes one replacement (`based_on` the old set) that waits beside the original, marked `replaces`, until a person discards one of them. The agent never discards anything, so replacing creative stays a person's decision (rule 3), as brief revisions wait as proposals (S3-3).
- **One full run per signed-off version.** A second full Copy run is refused while the version has current sets ("use New words on a set, or discard the sets first"), so the gallery never doubles silently.
- **Append-only table.** `copy_sets` allows insert and an update of `discarded_at` only (a column grant and a guard trigger; clearing it is the undo). A deleted run clears `run_id` and leaves the words. Parents are referenced by `(id, workspace_id)`, and the brief version by `(campaign_id, brief_version)`.
- **Model:** Sonnet (Q3), 4,000 output tokens, enough for 27 sets (three audiences across four channels).

**Consequences.** The capitalised-name check makes Title Case headlines fail once and be repaired into sentence case, which costs a repair on some real runs. The first-person rule refuses a brand that writes as "I" (a sole trader, say); none of the demo brands does. Hand-edit figures are judged against the brief's evidence as it is when the copy is read, so a figure can lose or gain its "added by a person" mark if the context changes, as with briefs.
